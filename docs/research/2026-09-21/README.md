## Core pipeline

`INGEST -> VERIFY PROVENANCE -> EXTRACT SAFE LESSON -> FORM HYPOTHESIS -> SIMULATE -> EVALUATE -> SAFETY REVIEW -> PRIOR-ART REVIEW -> REPRODUCE -> PROMOTE OR REJECT -> PUBLISH`

## Safety boundary

Physical autonomy is simulation-first. Consequential real-world actions require explicit authorization, bounded scope, logging, rollback, and policy approval. This release does not operationalize weapon targeting, payload actuation, detonators, or autonomous kinetic authority.

## Evidence rule

A source can be useful without constituting a discovery. Patent publications are treated as prior art/research inputs and remain attributed to their applicants/inventors. A “breakthrough” label is reserved for reproducible, materially novel findings that survive prior-art review and controlled validation.
